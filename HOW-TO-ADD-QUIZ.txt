========================================
 HOW TO ADD QUIZZES TO LESSONS
========================================

SUPER EASY! Just 2 steps:

STEP 1: Add quiz data to your lesson file
------------------------------------------
At the END of any lesson markdown file, add:

{% capture quiz_data %}
[
  {
    "question": "Your question here?",
    "options": [
      "Option A",
      "Option B",
      "Option C",
      "Option D"
    ],
    "correct": 0,
    "explanation": "Why this answer is correct"
  },
  {
    "question": "Another question?",
    "options": ["A", "B", "C", "D"],
    "correct": 2,
    "explanation": "Explain why option C is right"
  }
]
{% endcapture %}
{% include csp/p4-lesson-quiz.html quiz_data=quiz_data quiz_title="My Quiz Title" %}


STEP 2: That's it!
------------------------------------------
Your quiz will automatically appear with:
- Interactive multiple choice
- Instant feedback (green=correct, red=wrong)
- Explanations after each answer
- Progress tracking
- Final score screen
- Beautiful modern design


QUIZ DATA FORMAT
================

Each question needs 4 things:
1. "question" - The question text
2. "options" - Array of 4 answer choices
3. "correct" - Index of correct answer (0=A, 1=B, 2=C, 3=D)
4. "explanation" - Why the answer is correct

TIPS
====

✓ Use 4 options for each question (A, B, C, D)
✓ Make explanations helpful and educational
✓ Test actual understanding, not memorization
✓ Keep questions clear and concise
✓ Use real-world examples when possible

✗ Don't make questions too easy or too hard
✗ Don't use trick questions
✗ Don't have multiple correct answers
✗ Don't skip explanations

TROUBLESHOOTING
===============

Quiz doesn't appear?
- Check JSON syntax (commas, quotes, brackets)
- Validate correct indices are 0, 1, 2, or 3
- Ensure quiz_data variable name matches

Quiz shows but buttons don't work?
- Check browser console for errors
- Make sure all questions have exactly 4 options
- Verify JSON is valid

Need help?
- Look at the example on lesson 3-1-1
- Ask in team chat
- Check browser console for errors
